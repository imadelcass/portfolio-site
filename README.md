# imadelcass.netlify.app — portfolio

Vue 3 + Vite + Tailwind CSS. Single scrolling page, plus a route per project.

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # -> dist/
npm run preview   # serve dist/
npm run lint
```

## Structure

```
src/
  data/projects.js     ← every project + app. ADD NEW WORK HERE.
  data/resume.js       ← skills, experience, education, contact
  lang/locales/{fr,en}.json   ← all copy, including project descriptions
  sections/            ← the six blocks of the one-page layout
  components/          ← TheNav, TheFooter, ProjectCard
  views/Home.vue       ← assembles the sections
  views/Project.vue    ← /project/:slug detail page
```

Content lives in `data/` + `lang/`; components read from them. **No copy is
hard-coded in a component** — if you are editing text, you are in a locale file.

## Adding a project

1. Add an entry to `src/data/projects.js`. Required: `id`, `slug`, `type`
   (`web` | `mobile`), `name`, `stack`, and the three i18n keys
   (`tagline`, `desc`, `body`).
2. Add those three keys under `projects-info.<slug>` in **both**
   `lang/locales/fr.json` and `lang/locales/en.json`.
3. Drop images in `src/assets/img/` and import them. For a Play Store app, put
   `<slug>-icon.webp` and `<slug>-{1..8}.webp` in `src/assets/img/apps/` and use
   the `appIcon()` / `appShots()` helpers.
4. Set `store: 'play'` to get the Google Play badge, and
   `shotOrientation: 'portrait'` for phone screenshots (they render in a
   horizontal scroller) or `'landscape'` for wide ones (grid).

## Images

Everything raster is **WebP**. Converting the originals took the image payload
from 5.2 MB to ~600 KB. There is no ImageMagick on the dev machine — use ffmpeg:

```bash
# phone screenshot
ffmpeg -y -i shot.png -vf "scale='min(640,iw)':-1" -c:v libwebp -quality 80 shot.webp
# logo
ffmpeg -y -i logo.png -vf "scale='min(400,iw)':-1" -c:v libwebp -quality 88 logo.webp
```

Play Store assets are fetched from the listing page; see `../PLAYBOOK.md`.

## Theme

The palette is the CV's (see `../PLAYBOOK.md` §4) and lives in
`tailwind.config.js`: `navy`, `gold`, `cream`, `sand`. Fonts are Cormorant
Garamond (`font-display`) and DM Sans (`font-sans`).

Two gotchas worth knowing:

- **Cormorant defaults to old-style figures**, so `Ma3ahid` and `10` render with
  dropped numerals. `main.css` forces `font-variant-numeric: lining-nums` on
  `.font-display`. Don't remove it.
- **Dark mode is a `dark` class on `<html>` only.** An inline script in
  `index.html` sets it before first paint (no flash); `stores/modeStore.js` owns
  it afterwards and persists to `localStorage`. Never toggle a second class on
  `body` — that was the old bug.

## Testing responsive layout

`--window-size` in headless Chrome does **not** give you a mobile layout
viewport; it renders the desktop layout and crops, which looks exactly like a
broken responsive layout. To check a real narrow viewport, load the site in a
`390px` iframe from a scratch page and measure `scrollWidth` inside it, or use
real device emulation.
